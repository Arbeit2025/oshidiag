# 推し診断票メーカー（oshidiag）

好きな対象（キャラクター・選手・作品・場所など何でも）のステータスを入力すると、健康診断票風の1枚サマリーを生成するツールです。

## 使い方

1. 対象名、カテゴリ、総合コメント、最大6項目のステータス（項目名＋0〜100のスコア）を入力して「診断票を作る」を押します。
2. 詳細ページでは、スコアが CSS のバーで表示され、平均点と総合評価（S〜D）が出ます。
3. 診断票が2件以上あれば、一覧ページ下部のフォームから2件を選んで横並び比較ができます。
4. 診断票は一覧から削除できます。

データは SQLite に保存されます（ステータスは JSON 形式）。DB のパスは環境変数 `OSHIDIAG_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- スコアや評価は完全に入力した人の主観です。客観的な診断ではありません。総合評価（S〜D）は単純な平均点によるものです。
- 画像としての書き出し（PNG 化・SNS シェア用画像）は未対応です。画面のスクリーンショットで代用してください。
- ログイン機能はありません。Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。
